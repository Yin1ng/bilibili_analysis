# 数据说明

## 原始数据（三周采集）

| 文件 | 说明 |
|------|------|
| b站热门视频20260726.csv | 第 1 周采集，641 条 |
| b站热门视频20260802.csv | 第 2 周采集，651 条 |
| b站热门视频20260810.csv | 第 3 周采集，636 条 |

**来源**：B站官方热门榜接口 `api.bilibili.com/x/web-interface/popular`，每页 50 条，共 14 页/天。

## 中间数据

| 文件 | 说明 |
|------|------|
| b站热门数据_汇总.csv | 三周合并 + 按 BV号 去重（保留最新日期），1,926 条 |
| b站数据_清洗后.csv | 清洗 + 特征工程后，1,922 条（剔除 4 条超 10h 极端视频） |

## 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| 标题 | str | 视频标题 |
| UP主 | str | 创作者名称 |
| 分区 | str | B站内容分区 |
| 播放量 | int | 总播放次数 |
| 点赞数/评论数/弹幕数/收藏数/投币数/分享数 | int | 六项互动指标 |
| 时长秒 | int | 视频时长（秒）|
| 发布时间 | str | 发布时间（YYYY-MM-DD HH:MM:SS）|
| BV号 | str | 视频唯一标识（用于去重）|
| 数据日期 | str | 采集日期（YYYYMMDD）|

## 特征工程（清洗后 CSV 新增列）

| 字段 | 公式 |
|------|------|
| 点赞率/投币率/收藏率/评论率/弹幕率/分享率 | 互动数 ÷ 播放量 |
| 三连率 | (点赞+投币+收藏) ÷ 播放量 |
| 币赞比 | 投币数 ÷ 点赞数 |
| 弹幕密度 | 弹幕数 ÷ 时长秒 |
| 发布天数 | 数据日期 - 发布时间 |
| 播放分层 | 按播放量分位：尾部/腰部/头部爆款/超级爆款 |

## 复现方式

运行 `src/merge_bilibili.py` 可从三周原始数据重新生成汇总数据，运行 `src/analysis.py` 可重新生成清洗后数据与分析结果。
