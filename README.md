# B站热门视频流量规律分析

> 通过分析 B站官方热门榜数据，回答"什么样的内容更容易火"，给创作者选题和平台运营提供数据参考。

## 项目背景

B站每天产生海量内容，但"什么样的内容更容易火"，创作者和运营主要靠经验判断。热门榜代表"平台认为值得火的内容"，正好匹配分析目标。

## 数据集

- **来源**：B站官方热门榜接口 `api.bilibili.com/x/web-interface/popular`
- **规模**：三周采集（2026-07-26 / 08-02 / 08-10），合并去重后 **1,926 条唯一热门视频**
- **字段**：播放量、点赞/评论/弹幕/收藏/投币/分享数、分区、UP主、时长、发布时间等 14 个

## 分析方法

### 1. 播放量分布特征
- 均值 154万 vs 中位数 101万（比值 1.52），数据右偏
- 取对数后接近钟形 → 幂律分布，少数头部视频拿走绝大部分播放

### 2. 分区维度
- 三维视角：流量（播放中位数）+ 互动意愿（三连率）+ 爆款率
- **流量与互动负相关**：大众区（搞笑、小剧场）播放高但三连率低，小众创作区（VOCALOID、MAD、绘画）播放低但互动极强
- 爆款率（日均播放口径）：动物二创 42.9%、社会 28.6%、特摄 27.3% 居前（小样本分区），主流分区稳定产出

### 3. UP主维度
- 集中度：**前 14% UP主（151人）贡献 50% 播放**，前 56% 贡献 90%
- 头部均播 403万 vs 尾部 53万（差 7.7 倍）
- 小 UP（后 30%）无一产出爆款 → 头部垄断显著

### 4. 时长维度
- 0-1 分钟视频播放中位数（162万）与三连率（0.111）双第一
- 爆款更短：中位 206 秒 vs 普通 257 秒

### 5. 相关性与互动质量（核心发现）
- 绝对互动数与播放强相关（点赞×播放 0.80）
- **互动率与播放全部负相关**（投币率 -0.43、评论率 -0.44）
- **弹幕密度是唯一强正相关（+0.543）**——弹幕是独立的质量维度

### 6. 爆款画像 + 逻辑回归
- 爆款信号：弹幕密度（爆款 36.46 vs 普通 11.49，3.2 倍）
- 逻辑回归验证：弹幕密度（+1.43）、投币率（+0.69）是成为爆款最强的正向驱动
- 分层口径说明：按**日均播放量**（播放÷发布天数）分层，消除发布天数差异，避免老视频因播放累积而天然靠近爆款线
- **样本口径**：剔除发布不满 24 小时的新视频（510 条），仅保留已满 1 日的 1,299 条视频做分析（新视频播放未充分累积、标签不可靠），模型另用于新视频爆款潜力预测演示

## 主要结论

| 维度 | 结论 |
|------|------|
| 播放分布 | 幂律分布，右偏严重，中位数才有代表性 |
| 分区 | 流量≠互动；动物二创/社会/特摄爆款率高（小样本分区） |
| UP主 | 前 14% 贡献 50% 播放，头部高度集中 |
| 时长 | 短视频（0-1分钟）最优，爆款整体偏短 |
| 互动 | 高播放≠高互动率；弹幕密度是唯一正相关 |
| 爆款核心 | 弹幕活跃 + 投币硬核，而非表面互动率 |

## 局限性

- 数据来自热门榜（平台推荐结果），结论限定为"进入热门的视频"，不推广到全站
- 近 7 天快照，星期/时段分析存在选择偏差，无因果意义
- 无粉丝量、完播率、推荐量字段，无法完全解释播放差异
- 互动是播放的结果而非原因，所有结论为相关性，不做因果推断
- 播放分层基于日均播放量（已消除发布天数差异），但小样本分区（5-7条）的爆款率参考价值有限
